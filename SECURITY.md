# Security Policy

## Supported Versions

This project is currently under active development.

Security fixes are applied only to the latest version available in the repository.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, report it responsibly by contacting the repository owner directly.

Please include:

- Description of the vulnerability
- Potential impact
- Steps to reproduce
- Suggested remediation (if available)

Reports will be reviewed as soon as possible.

---

## Scope

This project is intended for educational and portfolio purposes.

Areas that may be considered security-sensitive include:

- Environment variable handling
- LocalStack and S3 integrations
- Selenium automation
- Dependency management
- Database access and credentials

---

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing any vulnerability.

Thank you for helping improve the security and reliability of the project.
