# Sandbox — PDI

This directory contains experimental scripts and exploratory implementations used during the development of the PDI pipeline.

## Purpose

The sandbox is intended for:

- prototyping new ideas and transformations;
- testing ingestion and processing approaches before promoting them to the main pipeline;
- validating experiments related to scraping, transformation logic, and data preparation.

---

## Contents

| File | Purpose |
|------|---------|
| [initial_scraping.py](initial_scraping.py) | Early experiments with the scraping workflow |
| [raw_wide_silver_transformation.py](raw_wide_silver_transformation.py) | Prototype for raw-to-wide and wide-to-silver transformation logic |
| [refactor_scraping.py](refactor_scraping.py) | Refactored scraper experiments and testing |

---

## Notes

Files in this folder are not necessarily part of the production execution path and may be used as reference material or development playgrounds.
